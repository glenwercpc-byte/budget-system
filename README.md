# CCPC 연간 예산 편성 시스템

시카고 언약 장로교회 팀별 예산 입력 · 총괄 · 승인 시스템
GitHub Pages(화면) + Google Apps Script(API) + Google Sheets(데이터베이스)

## 파일 구성

| 파일 | 위치 | 설명 |
|---|---|---|
| `index.html` | GitHub 저장소 | 입력 화면 (팀 목록 · 팀별 입력 · 관리자 총괄) |
| `demo-data.js` | GitHub 저장소 (선택) | `API_URL`이 비어 있을 때만 쓰는 데모 데이터 |
| `apps-script/Code.gs` | Apps Script | API 백엔드 |
| `apps-script/Seed.gs` | Apps Script | 2027년 예산용 초기 데이터 + `setup()` 설치 함수 |

## 1. 구글 시트 + Apps Script 설치 (최초 1회)

1. Google Drive에서 새 스프레드시트를 만듭니다 (예: `CCPC 예산 편성`).
2. **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 지우고 `apps-script/Code.gs` 전체를 붙여넣습니다.
4. **+ → 스크립트**로 `Seed` 파일을 하나 더 만들고 `apps-script/Seed.gs` 전체를 붙여넣습니다.
5. 위쪽 함수 선택에서 **setup**을 고르고 ▶ **실행**합니다. 권한 요청이 나오면 승인하세요.
   - 시트 7개(Config, Teams, Accounts, BaseLines, Budget, Status, Actuals_Import)가 만들어지고 계정 47개, 항목 140개가 들어갑니다.
6. 비밀번호를 설정합니다.
   - **Config** 시트 `adminPassword` → 관리자 비밀번호 (총괄표 · 승인 · 새 연도 만들기에 사용)
   - **Teams** 시트 `password` 열 → 팀별 비밀번호 (비워 두면 비밀번호 없이 입력 가능). 관리자 비밀번호로는 모든 팀에 들어갈 수 있습니다.
7. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 후 나오는 웹 앱 URL(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영됩니다. URL은 그대로 유지됩니다.

## 2. GitHub Pages 올리기

1. `index.html`을 열어 위쪽의 `var API_URL = '';`에 복사한 웹 앱 URL을 넣습니다.
   ```js
   var API_URL = 'https://script.google.com/macros/s/XXXXXXXX/exec';
   ```
2. 새 저장소(예: `ccpc-budget`)에 `index.html`을 올립니다. `demo-data.js`는 연결 후에는 필요 없습니다.
3. **Settings → Pages → Branch: main / root**로 저장하면 `https://<계정>.github.io/ccpc-budget/` 주소가 생깁니다.
4. CCPC Information Center에 링크를 추가하면 다른 시스템과 함께 쓸 수 있습니다.

## 3. 팀 담당자 사용법

1. 팀 카드를 누릅니다 (비밀번호가 있으면 입력).
2. 계정마다 2026년 1~9월 실적이 항목별로 미리 채워져 있습니다. 항목 아래에 건수 · 개월 수 · 주요 거래처가 보입니다.
3. 항목마다 **산출 방식**을 확인합니다. 실적 패턴에 따라 추천 방식이 미리 골라져 있습니다.

| 산출 방식 | 기준액 | 계산 |
|---|---|---|
| 매월 고정 | 월 금액 | 월 금액 × 12 |
| 변동 | 9개월 실적 | 9개월 실적 ÷ 9 × 12 |
| 연1회·일회성 | 예정 금액 | 입력한 금액 그대로 |
| 신규 사역 | 예정 금액 | 입력한 금액 그대로 |
| 제외 | — | 0 (환불·조정 항목) |

4. 요금 인상은 **인상률(%)**, 난방비 · 연말 행사 같은 4분기 증가분은 **조정액($)**에 넣습니다. 산출 근거 문장이 자동으로 만들어지고, 옆 칸에 메모를 덧붙일 수 있습니다.
   - 예: `9개월 실적 $39,372 ÷ 9 × 12 × 인상 5% + 조정 $1,000 — 2027년 식자재 가격 인상 반영`
5. 새 사역은 계정 아래 **+ 신규 항목**으로 추가합니다.
6. 작성자 이름을 넣고 **임시 저장**, 다 되면 **제출**을 누릅니다. 승인 전까지는 제출 후에도 고칠 수 있습니다.

## 4. 관리자 (재정팀)

- 상단 **관리자 총괄** → 관리자 비밀번호 입력
- 2026년 결산 보고서와 같은 구조(수입 → 팀별 지출 → 소계 → 합계 → 수지)로 2026 예산 / 9개월 실적 / 12개월 예상 / 2027 예산안 / 증감이 나옵니다.
- 계정 행을 누르면 항목별 금액과 산출 근거가 펼쳐집니다.
- 팀별 **승인** / **반려**(의견 입력). 반려된 팀은 화면 위에 의견이 보이고, 승인된 팀은 더 고칠 수 없습니다.
- **CSV 다운로드**로 항목별 상세를 엑셀에서 열 수 있습니다.
- 스프레드시트 메뉴 **예산 시스템 → 예산 총괄표 시트 만들기**를 누르면 인쇄용 `Summary_2027` 시트가 만들어집니다.

## 5. 매년 반복하기 (2028년 예산부터)

1. 재정팀이 새 기준 실적(예: 2027년 1~9월)을 **Actuals_Import** 시트에 붙여넣습니다.

| acct | category | actual9 | lines | months |
|---|---|---|---|---|
| 6100 | Utilities - Gas Heating (Nicor) | 7120.40 | 9 | 9 |
| 3600 | Sunday Lunch Supplies | 41250.00 | 130 | 9 |

   - `acct`는 예산 계정 번호(1201·1202·1205는 `1200`으로)를 씁니다. 항목 이름에 Refund가 들어가면 자동으로 ‘제외’, Insurance · Trip · Membership 등은 ‘연1회·일회성’으로 추천됩니다.
2. 관리자 총괄 맨 아래 **새 예산 연도 준비**에서 연도(2028)와 기준 기간을 넣고 **새 연도 만들기**를 누릅니다.
   - 계정 · 팀 구성은 전년도를 그대로 복사합니다.
   - 전년도 확정 예산안(Budget 합계)이 ‘전년 예산’이 됩니다.
   - 실적이 없는 계정은 전년도 예산 항목을 실적 0으로 가져옵니다.
3. 상단 연도 선택에 2028년이 생기고, 각 팀이 같은 방식으로 입력합니다.
4. 계정이나 팀 배정이 바뀌면 **Accounts** 시트의 해당 연도 행을 직접 고치면 됩니다 (`teamId`는 Teams 시트의 ID).

## 6. 초기 데이터(2027년) 기준

- 출처: `2026_Budget_vs_9-Month_Actual_Comparison.xlsx`(계정 · 2026 예산 · 9개월 실적 · 12개월 예상), `Jan thru Sept ALL EXPENSES BY CATEGORY.xlsx`(계정별 항목 · 건수 · 거래처)
- 계정별 항목 합계는 9개월 실적과 모두 일치합니다 (지출 합계 $580,698.88).
- **총무팀 담당 계정**: 안내문에 ‘2200’으로 되어 있으나 2200(영상부 장비)은 예배팀 계정이므로, 총무팀은 **1100 총무부**로 배정했습니다.
- **1200 인사부**: 1201 Administration · 1202 Pastor · 1205 Employer FICA & Medicare 항목을 한 계정 안에 모았습니다 (항목명 앞에 하위 계정 표시).
- **9150 SBA 대출 이자**는 재정팀에, **수입 계정(900~998)**은 ‘수입 (재정팀)’ 카드에 배정했습니다.
- 5350 / Education Pastor Payroll, 5402 / EM Pastor, 9900 / Wages처럼 서로 상계되어 합이 0인 재분류 항목은 넣지 않았습니다.
- 사례비 계정(1200, 2210, 2510, 2515, 5005, 5403, 6500)은 개인별 금액이 보이지 않도록 거래처 정보를 넣지 않았습니다.
- 급여 조정(Journal Entry) 같은 마이너스 항목은 순액이 맞도록 ‘변동’으로 남겨 두었습니다. 재정팀이 확인 후 조정하세요.

## 문제 해결

- **“서버에 연결하지 못했습니다”**: `API_URL`이 `/exec`로 끝나는지, 웹 앱 액세스가 ‘모든 사용자’인지 확인하세요.
- **고친 내용이 안 보임**: GitHub Pages 캐시 때문일 수 있습니다. 몇 분 뒤 강력 새로고침(Ctrl+Shift+R)을 해 보세요. Apps Script는 새 버전으로 재배포해야 합니다.
- **계정 번호가 날짜로 바뀜**: 시트는 계정 · 항목 ID 열을 텍스트 형식으로 만들어 두었습니다. 직접 붙여넣을 때도 ‘서식 없이 붙여넣기’를 쓰세요.
